<h3 align="left"> AI work</h3>

| Project | What it is | Stack |
|---|---|---|
| [OREN](https://github.com/felipe-nantes/OREN) | Medical imaging pipeline: liver MRI to a patient-specific 3D model, with deep learning segmentation and a local medical LLM behind schema guardrails and mandatory human review | Python, PyTorch, FastAPI, TotalSegmentator, MedGemma, Ollama |
| [decria-sec](https://github.com/felipe-nantes/finetunning) | End-to-end QLoRA fine-tune of Qwen3 into a bilingual cybersecurity assistant, built around a GTX 1060 3GB: dataset, synthetic data, training, evaluation, GGUF export | PyTorch, Transformers, PEFT, TRL, llama.cpp |
| [TRAINING](https://github.com/felipe-nantes/training-ai-overview) | Production platform that generates training programs with Claude agents inside a validated state machine, with an evaluation harness. 100+ programs generated. Overview only, code is private | TypeScript, Anthropic SDK, Next.js, Supabase, Fly.io |
| [GSUS Auditoria](https://github.com/felipe-nantes/gsus-auditoria-overview) | Hospital audit assistant in daily use: read-only automation, deterministic rules and a local Llama 3.1 8B, fully on-premise. Overview only, code is private | Python, Playwright, llama.cpp, SQLite |
